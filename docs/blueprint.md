# **App Name**: Ruta Segura

## Core Features:

- Navegación Fija: Header siempre visible con enlaces de navegación a todas las secciones de la página para fácil acceso.
- Sección Hero Dinámica: Sección inicial destacada con un mensaje impactante, llamado a la acción para la academia de conducción y posibilidad de imagen o video de fondo.
- Detalles de Soluciones y Servicios: Presentación clara y concisa de los cursos, servicios y metodologías de enseñanza que ofrece la academia.
- Carrusel de Testimonios: Visualización atractiva de testimonios de alumnos satisfechos en un carrusel interactivo.
- Exhibición de Planes y Paquetes: Sección dedicada a mostrar los diferentes planes y paquetes de clases, incluyendo precios y lo que ofrece cada uno.
- Ubicación y Formulario de Contacto: Mapa interactivo de la ubicación de la academia y un formulario sencillo para que los visitantes puedan contactar o pedir información.
- Asistente AI de Preguntas Frecuentes: Un asistente conversacional que utiliza una herramienta de IA para responder a las preguntas más comunes sobre la academia, horarios o requisitos, mejorando la experiencia del usuario.

## Style Guidelines:

- Esquema de colores claro y profesional, priorizando la legibilidad. Se usa el azul como color principal (#297BE0) para transmitir confianza y autoridad, complementado con el color de fondo y acento.
- Color de fondo: Un azul muy claro y sutil (#ECF2FC) para mantener la interfaz limpia y abierta, incorporando el concepto de 'blanco' solicitado por el usuario y el 'negro' para los textos.
- Color de acento: Un violeta profundo (#4C1FA3) para puntos clave y llamados a la acción, que proporciona contraste y un toque moderno, derivado análogamente del azul principal sin usar tonalidades teal.
- Tipografía para titulares y cuerpo de texto: 'PT Sans', un sans-serif humanista, para una lectura clara, amigable y profesional, coherente con el nicho de educación y servicio.
- Iconografía limpia y moderna: Utilizar iconos SVG para las secciones y servicios que refuercen los conceptos de seguridad, educación y movilidad.
- Maquetación responsive y modular: Diseño que se adapta a cualquier dispositivo, con un header fijo en la parte superior para facilitar la navegación constante y secciones bien definidas con espacio en blanco abundante.
- Animaciones sutiles y significativas: Efectos de hover suaves en los botones, transiciones fluidas entre secciones y cargas de contenido progresivas para una experiencia de usuario refinada.
